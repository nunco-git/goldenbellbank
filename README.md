# 독서골든벨 문제은행

독자가 읽은 책마다 문제(객관식/O·X/주관식)를 직접 등록하면 **별도 검수 없이 바로** 문제은행에
쌓이고, 도서를 선택하면 그 도서의 문제 중 원하는 개수만큼 무작위로 뽑아 골든벨을 진행할 수
있는 웹앱입니다. 다른 이용자가 문제에 오류가 있다고 판단하면 오류 신고(수정 제안)를 남길 수
있고, 이용자 2명 이상이 동의하면 자동으로 문제 내용이 수정됩니다. Firebase(Firestore+Storage+Auth)
+ GitHub Pages 조합으로 동작합니다.

## 주요 기능

- 구글 로그인(Firebase Auth)
- 도서 등록: 제목/저자/역자(선택)/출판사
- 문제 등록: 도서 선택 → 유형(객관식/OX/주관식) → 문제/정답 입력 → **등록 즉시 사용 가능** (별도 승인 절차 없음)
  - 참고 사진(책 페이지 촬영) 업로드 → "사진에서 텍스트 읽어오기" 버튼으로 OCR(Tesseract.js, 한글 지원) 텍스트 자동 추출
  - 등록자 이름/소속/나이는 모두 선택 입력
- "문제 둘러보기" 탭: 전체 이용자가 등록된 문제를 확인하고 **오류 신고**(수정 제안: 사유 + 수정할 문제 내용/정답)를 남길 수 있음
  - 신고자 본인을 제외한 다른 이용자가 "동의" 버튼을 눌러 찬성 표를 던지고, **2명 이상 동의 시 자동으로 원본 문제에 반영**됨
- 관리자 전용 "정정 내역" 탭: 전체 오류 신고(대기 중/반영됨) 내역을 확인하고 필요 시 삭제 가능
- "독서골든벨" 탭: 도서 선택 → 문제 수·유형 지정 → 등록된 문제 중 무작위 출제 → 정답 공개/다음 문제 진행
- "랭킹" 탭: 이용자별 문제 등록 수 순위와 등급(총 10단계: 일반 / 브론즈1~3 / 실버1~3 / 골드1~3) 표시
  - 현재는 등급 **표시만** 제공되며, 등급별 권한(예: 정정 투표권, 신고 가중치 등)은 추후 필요 시 추가할 수 있도록 구조만 마련해 두었습니다.

## 파일 구성

```
reading-goldenbell/
├─ index.html
├─ css/style.css
├─ js/firebase-config.js   ← Firebase 프로젝트 키 입력 필요
├─ js/app.js
├─ firestore.rules         ← Firestore 보안 규칙
├─ storage.rules           ← Storage 보안 규칙
└─ README.md
```

## 1. Firebase 프로젝트 설정

1. https://console.firebase.google.com 에서 새 프로젝트 생성
2. **Authentication** → 로그인 방법 → "Google" 사용 설정
3. **Firestore Database** → 데이터베이스 만들기 (프로덕션 모드)
4. **Storage** → 시작하기 (기본 버킷 생성)
5. 프로젝트 설정(⚙️) → "내 앱" → 웹 앱 추가(</> 아이콘) → 앱 닉네임 입력 후 등록
6. 발급된 `firebaseConfig` 값을 복사하여 `js/firebase-config.js` 파일의
   `firebaseConfig` 객체에 그대로 붙여넣기

```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "...",
};
```

## 2. 보안 규칙 적용

- Firestore Database → 규칙 탭 → `firestore.rules` 내용을 붙여넣고 게시
- Storage → 규칙 탭 → `storage.rules` 내용을 붙여넣고 게시

두 규칙 모두 "로그인한 사용자만 사용 가능"을 기본으로 합니다. 문제 등록에는 승인 절차가 없으므로
로그인한 사용자는 바로 문제를 등록할 수 있고, 오류 신고에 대한 동의(2명 이상) 시 문제 내용이
자동으로 수정됩니다. 도서 수정·삭제와 정정 내역 삭제만 `role: "admin"`인 사용자로 제한됩니다.

> 오류 신고 2명 동의 시 문제 문서를 갱신하는 로직은 클라이언트(브라우저)에서 실행됩니다. 소규모
> 내부 이용자를 대상으로 하는 서비스라 단순하게 구성했으며, 악의적인 조작을 엄격히 막아야 한다면
> 추후 Cloud Functions로 투표 집계·반영 로직을 옮기는 것을 권장합니다.

## 3. 관리자 지정

1. 관리자로 지정할 사람이 앱에 구글 로그인을 한 번 합니다.
   (로그인하면 Firestore `users` 컬렉션에 본인 문서가 자동 생성됩니다.)
2. Firebase 콘솔 → Firestore Database → `users` 컬렉션 → 해당 사용자 문서(uid) 찾기
3. `role` 필드 값을 `"user"` → `"admin"` 으로 수정

관리자로 지정된 계정은 로그인 시 상단에 "관리자" 배지가 표시되고 "정정 내역" 탭이 나타납니다.

> 참고: `js/firebase-config.js` 안의 `BOOTSTRAP_ADMIN_EMAILS` 배열에 이메일을 넣어두면,
> 그 이메일로 **최초 로그인할 때** 자동으로 admin 권한이 부여됩니다(선택 사항).

## 4. Authentication 승인 도메인 등록

Authentication → Settings → 승인된 도메인에 배포할 GitHub Pages 도메인
(예: `your-id.github.io`)을 추가해야 구글 로그인이 정상 동작합니다.

## 5. GitHub Pages 배포

1. GitHub에 새 저장소 생성 (예: `reading-goldenbell`)
2. 이 폴더의 파일 전체를 저장소에 업로드(push)
3. 저장소 Settings → Pages → Branch를 `main`(또는 배포 브랜치) / 루트로 지정 후 저장
4. 잠시 후 `https://<사용자명>.github.io/reading-goldenbell/` 주소로 접속 가능
5. 위 4번 단계의 승인된 도메인에 `<사용자명>.github.io` 추가 확인

## 참고 사항

- 문제 사진은 Storage `questions/{도서ID}/{문제ID}.jpg` 경로에 저장됩니다.
- OCR은 브라우저 안에서(Tesseract.js) 처리되며 네트워크로 사진이 전송되지 않습니다.
  다만 정확도가 완벽하지 않으므로, 자동 추출된 텍스트는 등록 전에 확인/수정해 주세요.
- 도서 목록의 "등록 문제 N개" 배지는 골든벨 출제 가능한 문제 수를 보여줍니다.
- 필요하다면 `js/app.js`의 골든벨 로직(문제 수, 유형 필터, 셔플 방식)을 자유롭게 수정해 사용하세요.

## 등급(랭킹) 기준

`js/app.js` 상단의 `TIERS` 배열에서 문제 등록 수 기준을 조정할 수 있습니다. 기본값은 다음과
같습니다(낮은 등급부터):

| 등급 | 필요 등록 수 |
|---|---|
| 일반 | 0개 |
| 브론즈3 / 브론즈2 / 브론즈1 | 3개 / 6개 / 10개 |
| 실버3 / 실버2 / 실버1 | 15개 / 20개 / 30개 |
| 골드3 / 골드2 / 골드1 | 40개 / 60개 / 80개 |

현재는 등급이 랭킹 탭에 **표시만** 되며, 등급별로 실제 권한(예: 골드 등급만 정정 투표 가능,
브론즈 이하는 하루 등록 수 제한 등)을 부여하려면 `getTier()`가 반환하는 등급명을 참고해 각 기능
진입 지점에 조건을 추가하면 됩니다.
